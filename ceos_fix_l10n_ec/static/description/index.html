CEOS Fix EDI Ecuador

XML SRI, RIDE, secuencias y modos de emisión

Correcciones sobre la localización Ecuador de Odoo 19 (l10n_ec_edi y l10n_ec_edi_stock): XML de comprobantes, RIDE, secuencias y control de cómo se genera cada documento.

Qué incluye

  • Modo EDI por tipo de documento: autorizar en el SRI, solo exportar el XML a una carpeta, o no generar XML.
  • Campo adicional RUC Proveedor en factura, nota de crédito, nota de débito, retención, liquidación de compra y guía de remisión.
  • Ajustes del XML y del RIDE (etiquetas de RUC, cliente y fecha de autorización).
  • Asistente para sembrar y corregir secuencias de comprobantes electrónicos.
  • Guía de remisión: info adicional y flujo de envío alineado con el modo EDI de la compañía.
  • El RUC del proveedor del software se configura en Ajustes; el módulo no trae un RUC fijo.

Requisitos

Odoo 19 con Contabilidad Ecuador: account, l10n_ec, l10n_ec_edi, stock y l10n_ec_edi_stock. Licencia LGPL-3. Módulo gratuito.
