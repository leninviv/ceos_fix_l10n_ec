CEOS Fix EDI Ecuador se acopla a la localización contable y de facturación electrónica oficial de Odoo 19. No reemplaza l10n\_ec: hereda facturas, notas de crédito, notas de débito, retenciones, liquidaciones de compra y guías de remisión, y corrige y amplía el XML y el RIDE.



En Ajustes, cada tipo de documento puede trabajar en uno de tres modos: generar el XML y autorizarlo en el SRI desde Odoo, generar el XML y dejarlo en una carpeta, o no generar XML y usar solo la contabilidad. El directorio de exportación se configura en la compañía.



El XML incluye el campo adicional RUC Proveedor (el RUC del proveedor del software) en factura, nota de crédito, nota de débito, retención, liquidación de compra y guía de remisión. Ese valor se define en la instalación; el módulo no trae un RUC fijo.



También ajusta etiquetas del RIDE (RUC, cliente y fecha de autorización) e incluye un asistente para sembrar y corregir las secuencias de los comprobantes electrónicos, incluidas las guías de remisión cuando está instalado l10n\_ec\_edi\_stock
